Educational Architecture Framework

Instructional Design Prompt
Description A planning and instructional-design framework that transforms a textbook chapter, syllabus topic, lesson content, PDF, or educational material into a structured teaching blueprint. This prompt does NOT create videos. This prompt does NOT create Veo scenes. This prompt does NOT create lesson scripts. Its purpose is to create the educational architecture that will later be used by: * FlowForge EDU K–12 Master * FlowForge Course K–12 Master * FlowForge Practice K–12 Master * FlowForge Clarity Audit Master --- Input Material Analyze the following: [PASTE CHAPTER / LESSON / SYLLABUS / PDF CONTENT] --- Learning Context Grade Level: [Class 1–2 / Class 3–5 / Class 6–8 / Class 9–10 / Class 11–12] Curriculum: [CBSE / ICSE / State Board / NIOS / Other] Subject: [Subject] Audience Type: * Student Self-Learning * Parent-Assisted Learning * Classroom Learning --- Educational Design Philosophy Do not summarize the chapter. Do not rewrite the textbook. Do not create scripts. Instead answer: "How should this lesson be taught so that learners understand it most effectively?" Focus on: Understanding ↓ Learning ↓ Capability --- Analysis Process Perform all sections below. Do not skip any section. --- 1. Lesson Identity Provide: * Chapter Name * Topic Name * Subject * Grade Level --- 2. Lesson Purpose Answer: Why does this lesson exist? Why should learners study it? Why is it important? --- 3. Learning Goals Define: What learners should know, understand, and be able to do after completing the lesson. Separate: Knowledge Goals Understanding Goals Capability Goals --- 4. Prerequisite Knowledge Identify: What learners should already know before starting this lesson. Separate: Required Prior Knowledge Helpful Prior Knowledge --- 5. Concept Breakdown Break the lesson into its smallest teachable concepts. Provide: Concept 1 Concept 2 Concept 3 Concept 4 etc. Do not combine multiple concepts. --- 6. Learning Progression Map Create a logical learning sequence. Display: Starting Knowledge ↓ Concept A ↓ Concept B ↓ Concept C ↓ Concept D ↓ Lesson Understanding Explain why this sequence is optimal. --- 7. Core Concepts Identify: The most important concepts learners must understand. Rank: * Critical * Important * Helpful --- 8. Possible Confusion Points Predict: Where learners may struggle. For each confusion point provide: Confusion Why It Happens Suggested Clarification Important: These are predicted confusion points. Not actual learner feedback. --- 9. Common Misconceptions Identify: Incorrect beliefs learners may develop. For each misconception provide: Misconception Why It Happens Correction Strategy --- 10. Real-Life Relevance Answer: Why should learners care? Provide: * Everyday examples * Real-life applications * Practical significance --- 11. Learning Analogies Suggest: * Analogies * Comparisons * Mental models that make understanding easier. --- 12. Memory Anchors Suggest: * Visual memory anchors * Story anchors * Everyday associations that improve retention. --- 13. Parent Support Notes If audience includes parents: Provide: * Likely learner difficulties * How parents can help * Reinforcement ideas --- 14. Capability Building Opportunities Identify: What learners should eventually be able to DO. Examples: * Solve * Explain * Identify * Compare * Analyze * Apply --- 15. Practice Opportunities Recommend: What learners should practice. Separate: Basic Practice Intermediate Practice Advanced Practice --- 16. Assessment Opportunities Suggest: Ways to check understanding. Separate: Understanding Checks Application Checks Capability Checks --- 17. EDU Blueprint Recommend: Which concepts should appear in: FlowForge EDU K–12 Master Explain why. --- 18. Course Blueprint Recommend: Which concepts should appear in: FlowForge Course K–12 Master Explain why. --- 19. Practice Blueprint Recommend: Which concepts should appear in: FlowForge Practice K–12 Master Explain why. --- 20. Clarify Opportunities Predict: Which areas are most likely to generate future learner questions. These are candidates for future Clarify videos. --- 21. Educational Risk Analysis Identify: Potential risks such as: * Confusion * Cognitive overload * Weak prerequisite knowledge * Vocabulary difficulty * Abstract concepts Explain mitigation strategies. --- 22. Final Lesson Blueprint Provide a concise master blueprint containing: Lesson Purpose Learning Goals Learning Sequence Core Concepts Predicted Confusions Memory Anchors Practice Opportunities Assessment Opportunities Parent Support Notes Recommended EDU Topics Recommended Course Topics Recommended Practice Topics --- Output Philosophy The goal is not to summarize content. The goal is not to create a lesson. The goal is not to create a video. The goal is: Transform raw educational content into a teachable structure. Think like: * An instructional designer * A curriculum planner * A learning scientist * A learner advocate Always optimize for: Clarity ↓ Understanding ↓ Learning ↓ Capability
