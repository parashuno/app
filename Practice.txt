



# FlowForge Practice K–12 Master (Final Consolidated Version)

## Description

A production-grade Google Flow + Veo 3 framework for creating K–12 practice, application, worksheet, revision, problem-solving and exam-readiness videos using sequential 8-second Veo clips.

The purpose is to help learners successfully apply what they have already learned.

---

# Primary Objective

I want to create a practice-oriented learning video.

The goal is not to introduce a concept.

The goal is not to teach a chapter from scratch.

The goal is to help learners:

* Apply knowledge
* Solve problems
* Avoid mistakes
* Build confidence
* Strengthen retention

---

# Primary Educational Success Metric

The primary success metric is:

"Can learners successfully apply what they know?"

Every scene should move learners closer to successful performance.

If a scene does not improve capability, redesign or remove it.

# Production Environment

I will create this video using Google Flow and Veo 3.

The final practice session will be assembled using Flow's Add-to-Prompt workflow.

All scenes must feel like one continuous guided practice experience.

---

# Practice Philosophy

This is a PRACTICE SESSION.

Do NOT:

* Teach the entire lesson again
* Create a concept explainer
* Deliver information without application

Focus on:

Recall
↓
Apply
↓
Practice
↓
Correct
↓
Improve

Outcome:

Capability Building

---

# Mistake-Reduction Rule

The goal of practice is not repetition.

The goal is to eliminate confusion that causes mistakes.

Every practice step should:

* Reveal common mistakes
* Explain why mistakes occur
* Help learners avoid errors

Practice should build accuracy through understanding.

---

# One Scene = One Solvable Step Rule

Each scene should help learners complete one action.

Examples:

* Observe
* Recall
* Identify
* Apply
* Solve
* Verify

Avoid combining multiple major solving steps in one scene.

---

# Confidence Building Rule

Practice should increase confidence.

Learners should repeatedly feel:

"I can do this."

Avoid:

* Intimidation
* Excessive difficulty
* Sudden complexity

Build confidence progressively.

---

# Parent-Assisted Learning Rule

If Audience Type = Parent-Assisted Learning:

Include:

* Parent guidance
* Common learner mistakes
* Ways parents can support practice

---

# Age-Appropriate Practice Rule

Adapt:

* Question complexity
* Vocabulary
* Practice depth
* Reasoning level

to the selected grade level.

# Practice Summary Rule

At the end of the practice session provide:

---

## Practice Recap

Summarize:

* What was practiced
* What skills were developed
* What mistakes were addressed

Use age-appropriate language.

---

## Capability Summary

List:

* What learners can now do
* What learners can now identify
* What learners can now apply

Focus on capability rather than information.

---

## Capability Check

Create:

3 simple application-based questions.

Purpose:

* Verify capability
* Reinforce performance
* Encourage independent thinking

Do NOT make them difficult.

Do NOT turn this into an exam.

Do not provide answers immediately.

---

# Flow Add-to-Prompt Continuity Rules

Assume every scene begins immediately after the previous scene ends.

Maintain:

* Visual continuity
* Practice continuity
* Motion continuity
* Narration continuity
* Presenter continuity (if applicable)

Avoid:

* Hard resets
* Environment changes
* Style changes
* Re-explaining previously mastered steps

---

# Educational Effectiveness Rule

Every scene must contribute to at least one of:

* Capability Building
* Accuracy Improvement
* Mistake Reduction
* Confidence Building

If a scene contributes to none of these:

Redesign or remove it.

---

# Cognitive Load Rule

Keep tasks manageable.

Avoid:

* Multiple difficult steps in one scene
* Excessive information
* Long instructions
* Complex visual overload

Each scene should remain comfortably understandable within 8 seconds.

---

# Progressive Difficulty Rule

Build difficulty gradually.

Use:

Easy
↓
Moderate
↓
Application
↓
Independent Thinking

Avoid sudden jumps in complexity.
